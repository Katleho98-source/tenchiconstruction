##  Project Overview
Tenchi Construction is a multidisciplinary construction and architectural services firm established in 2018. The company specializes in technical 2D construction drawings, 3D interior design modeling, structural renovations, and turnkey building.

This repository contains the complete website proposal and HTML5 multi-page web application developed for Tenchi Construction. The web platform transitions the client from a static web presence into an interactive, lead-generating digital portfolio featuring dynamic 3D CAD modeling showcases and quotation intake tools.

---

##  Target Audience
* **Residential Homeowners:** Property owners seeking custom modern renovations, structural extensions, or 3D interior modeling.
* **Commercial Developers:** Real estate developers and commercial owners requiring code-compliant working drawings and structural builds.
* **Architects & Engineers:** Industry partners seeking outsourced 2D CAD drafting and high-definition 3D renderings.

---

##  Key Website Features
* **Multi-Page Semantic Structure:** Fully structured `index.html`, `about.html`, `services.html`, `portfolio.html`, and `contact.html` files.
* **Interactive Lead Capture:** Quote request form supporting CAD/blueprint file uploads (`.dwg`, `.pdf`, `.png`).
* **Visual Showcase Layouts:** Built-in support for WebGL 3D model viewers and before/after project transformation showcases.
* **Mobile-First Responsive Design:** Grid-based layout optimized across all modern screen resolutions.

---

##  Tech Stack & Specifications
* **Markup & Structure:** HTML5 (Semantic elements)
* **Styling Framework:** CSS3 / Tailwind CSS
* **Scripting & Visuals:** JavaScript (ES6+), Three.js (WebGL rendering)
* **Typography:** Aptos / Aptos Display
* **Color Palette:**
  * Dark Slate (`#1E232A`) – Represents durability and structure
  * Architectural White (`#F8F9FA`) – High-contrast readability
  * Industrial Orange (`#E65100`) – Primary CTA buttons
